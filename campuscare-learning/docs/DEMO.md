# 演示手册

用于课程进度汇报的现场演示，时长约 5 分钟。演示前启动服务，并准备三个浏览器标签
分别登录学生 `s2023001`、教师 `teacher`、系统管理员 `sysadmin`（密码均为
`Campus2026!`）。

## 0. 前置检查

- `python -B -m unittest discover -s tests -t .` 全部通过；
- 服务在 8840 端口运行；
- 演示数据未被上一轮操作修改，必要时删除 `data/learning.sqlite3` 后重启；
- 准备一份用于上传演示的 `.md` 文件（两到三个 `##` 章节即可）。

## 1. 开场（约 15 秒）

学习支持子系统包含两个模块。Module 1 对制度类问题给出带原文出处的回答，证据不足
时拒绝作答。Module 2 将学业风险转化为可复算的分数，达到阈值时自动通知学生与导师。
两个模块均不使用训练数据，因此采用检索与规则方法，不声称模型效果。

## 2. Module 1 演示（约 90 秒）

1. 使用 `s2023001` 登录，进入“智能问答”。
2. 提问“期末挂科了怎么办，会不会被学业预警”。
   - 回答超过 180 字时默认折叠，点击“展开全文”查看完整内容；
   - 该问题同时涉及两份文件，引用卡片给出 2 个来源，各带「原文 / Word」；
     点“原文”查看制度全文，点“Word”下载 `.docx`；
   - 回答下方给出 2–3 条追问建议（如“预警等级是怎么规定的？”），点击即可继续提问；
   - 右侧“回答依据”显示命中段落、相关度与引用条数。
3. 输入“食堂今天中午有什么菜”。
   - 最高相关度 2.0，低于阈值 4.0，系统拒绝作答，仅列出最接近的章节。
   - 说明该路径的作用：检索不到依据时不生成内容。
4. 补充说明：配置本地 Ollama 后切换为生成模式，检索结果仍约束模型逐句标注出处；
   模型不可用时自动退回抽取模式，界面注明实际使用方式。

## 3. Module 2 演示（约 100 秒）

1. 使用 `teacher` 登录，进入“学业风险”。
2. 说明顶部四项指标：所带学生 8 人、高风险 2 人、关注 2 人、平均风险分 36.6。
3. 点击第一行学生（陈杰，89 分，高风险）。
   - 说明四项指标的权重与贡献：30 + 24.6 + 14 + 20 = 88.6，与总分一致；
   - 说明下方列出最近 15 条考核记录，未提交的项单独标记，可作为申诉依据。
4. 关闭面板，说明“郑凯”（成绩良好但几乎不登录）仅为“关注”，单一弱信号不产生高风险。
5. 展示“系统通知”区域：高风险学生的自动预警同时出现在教师与学生两侧；点击任一条可展开
   完整内容。
6. 在依据面板的“向学生留言”中发送一条内容（也可留空，系统按主导因素自动生成），
   切换到 `s2023005` 的标签页，在“通知”区域可以看到该留言，并与“系统自动”标签区分；
   点击通知可打开弹窗查看全文并标为已读。

## 4. 角色分界演示（约 40 秒）

切换到 `sysadmin`：

- 界面只有“后台管理”，没有智能问答入口；
- 后台包含知识库、系统日志、账号一览三部分，不含任何学生成绩或风险数据；
- 上传准备好的 `.md` 文件，说明上传后立即重建索引；
- 说明教师同样无法进入该页面，两组接口互相返回 403，并有测试覆盖。

## 5. 边界说明（约 45 秒）

1. 数据：GCU 为虚构学校，12 名学生的成绩与行为记录由固定随机种子合成，数据库与
   界面均标注 synthetic。
2. 方法：Module 1 使用 BM25 检索与可选的预训练模型；Module 2 为规则引擎。缺少
   真实标签，训练模型得到的指标不具备解释力，因此未采用。
3. 验证：72 个自动化测试，覆盖引用编号一致性、角色越权、语料上传校验、自动预警
   冷却与通知隔离、CSRF。

## 6. 常见问题

| 问题 | 回答要点 |
|---|---|
| 为什么不用向量检索或大模型 | 课堂环境无法保证依赖安装与联网。检索接口独立，替换范围限于 `Index.search()`；Ollama 接口已预留，可在界面切换 |
| 四项指标的权重依据 | 依据校规第 2、3 条的触发情形与教务经验：提交与成绩合计 0.6，登录与问答各 0.2。口径通过接口公开，学生与教师看到同一份 |
| 为什么教师与系统管理员要分开 | 数据范围不同（教师按所带学生过滤，系统管理员无数据返回）、职责不同（面向学生与面向系统资产）、审计不同（留言记录作者，语料变更记录文件与时间） |
| 自动预警会不会打扰学生 | 阈值 60 分，且同一学生同一等级每周只发送一次；教师仍可在此基础上手动留言 |
