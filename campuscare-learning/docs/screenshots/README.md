# 界面截图

汇报与报告用图，1440 × 960 视口，headless Chrome 实际截取。
界面样式与主系统 `campuscare/web/style.css` 保持一致。

| 文件 | 内容 |
|---|---|
| `01-登录.png` | 登录页，学生、教师、系统管理员三类身份分栏 |
| `02-M1-智能问答.png` | 问答页初始状态与回答依据面板 |
| `03-M1-带出处回答.png` | 长回答默认折叠，引用卡片提供「原文 / 下载」 |
| `04-M1-回答展开.png` | 点击展开后的完整回答 |
| `05-M1-原文与下载.png` | 引用文档原文弹窗，可下载 `.md` |
| `06-M2-学生画像.png` | 风险分数、四项依据、下一步建议与通知 |
| `07-M2-通知详情.png` | 通知弹窗，显示完整内容并可标为已读 |
| `08-M2-教师风险名单.png` | 所带学生名单、系统通知列表 |
| `09-M2-学生依据抽屉.png` | 单项指标明细、贡献分与留言入口（选填） |
| `10-系统管理员后台.png` | 知识库、问答日志、知识缺口、账号一览 |

截图中的成绩与行为记录均为合成数据（`synthetic = 1`），引用时需保留数据来源说明。
