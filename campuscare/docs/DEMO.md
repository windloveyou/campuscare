# 8 分钟演示脚本

Windows 演示前，双击 [start-demo.cmd](../start-demo.cmd) 打开本机首页，演示时保持启动窗口开启。断网时可用已有演示账号完成业务流程；无需现场注册或收验证码。

## 1. 管理员看校园（1 分钟）

选择管理人员账号进入。展示校园总览、119项设施、待办、模拟数据标识。进入地图，点击 A 楼 → A-201 → 空调档案。解释状态来自工单，不是传感器。

## 2. 用户提交报修（2 分钟）

退出并选择学生账号。打开智能报修，选择教学楼 A → A-101-FAN-01。填写“吊扇开启后声音很大，今天上午开始，其他吊扇正常”。可上传一张你有权使用的真实图片；不上传也可以。

点击规则辅助整理。强调没有接模型时不声称看懂照片。检查标题、问题摘要及待确认信息。补充说明，确认位置并提交。

## 3. 管理员派单（1 分钟）

管理员在工单中心打开新工单，查看设施位置和报告内容，选择电工维修员（`tech`）并派单。已存在的工单可以展示等待配件等分支。

## 4. 维修与验收（2 分钟）

切换到电工维修员。打开该工单，填写检查说明后开始维修。填写实际处理结果后提交验收。切回报修学生，确认验收通过。展示完整时间线和设备记录状态更新。

若想展示闭环之外的情况，可选择“未解决/再次出现”，填写原因。工单回到待确认，旧维修分配清空。

## 5. 管理与预测（2 分钟）

管理员进入管理助手，查询“哪些设施反复报修”。展示结果来自数据库。进入维护与预测运行实验，解释独立设备划分及模拟数据限制；选择有历史记录的设备创建巡检，填写巡检结果。

## 注意

- GPS可真实请求权限，但虚拟校园不会与实际坐标强行匹配。
- 二维码是可扫描的设施链接；手机需要能访问服务器地址，默认 localhost 仅本机可用。
- 不报告虚构准确率。使用实际运行得到的合成测试指标，并展示规则基线。
- 目前未完成真实模型接入、真实校园数据验证、自动图像定位或语义去重。
